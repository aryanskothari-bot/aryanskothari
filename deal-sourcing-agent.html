FAQ

Good to know.

Where does the data come from?

Each run searches the live web and passes the top results to the agents. The sources used are listed next to the results so you can open and check them.

How is the score calculated?

The scoring agent rates each counterparty from 0 to 100 on eight pillars: strategic fit, financial capacity, value accretion, synergies, regulatory ease, cultural fit, deal precedent and timing. The total is a weighted average using your sliders.

Can I rely on the numbers?

Treat them as a first screen, not a valuation. Figures are AI estimates built from public sources; check them against filings and a market data provider before using them in a deal.

Is my search stored?

Only in your own browser, so your recent searches show up next time. Nothing is saved on a server.
